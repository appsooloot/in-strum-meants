# Sets 1 & 2 (Moonlit Lake, Spaceship Lounge) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the first two Sets, each a world, visual, original built-in instrument and ambience tied together by one mood. Along the way, build the reusable foundations: the Sound Core, the Ambience engine, Living Sky and the World Kit.

**Architecture:**
- A new C++17 target `InStrumDSP` holds all real-time DSP behind a small C API: Felt Glass, Orbit Pad, Space reverb and ambience generators.
- `InStrumAudio` wraps that DSP as in-process Audio Units (two instruments, one generator), so the existing `AudioEngine`, dial reader, touch curve and sound-character tap work unchanged.
- `InStrumCore` gains pure, testable models:
  - astronomy
  - weather
  - mood
  - patches
  - sets
  - the two worlds and their visuals
- `InStrumApp` gains the Living Sky shaders, the world renderers and the SwiftUI for sets, cards and the built-in instrument panel.

**Tech Stack:**
- Swift 5.10 tools (Swift 6.1 compiler, Swift 5 mode), SwiftPM.
- C++17 target with a C header.
- AVFoundation / AudioToolbox (AUAudioUnit subclasses, `AUAudioUnit.registerSubclass`).
- Metal (runtime-compiled shader sources, existing `RenderStack`).
- SwiftUI.
- XCTest.
- GitHub Actions macos-15.

**Spec:** `docs/superpowers/specs/2026-10-28-sets-1-2-design.md` (read it alongside this plan).

## Global Constraints

**Platform and dependencies**
- macOS 13.0 deployment. Release binary is x86_64 (Intel). CI tests run on macos-15 (Apple silicon). All code builds for both architectures.
- No third-party dependencies. No recordings or samples of any song. Every sound is synthesized.

**Sound Core rules**
- The audio thread never allocates memory, locks or logs.
- Denormals are flushed (x86 MXCSR FTZ/DAZ; arm64 FPCR FZ).
- Sample-accurate MIDI.
- Every dial change is smoothed.
- Voice stealing takes the quietest voice and fades it over **20 ms**.
- **Polyphony:** Felt Glass **32**, Orbit Pad **16**.
- **CPU budget, measured in CI:**
  - Felt Glass 16-note sustained chord + Orbit Pad 8-note chord + full ambience, all together: **< 8% of real time**.
  - Felt Glass alone with a 32-note pedalled run: **< 5%**.

**Tuning**
- A = 440 Hz.
- Fine tune **±50 cents**, Transpose **±12 semitones**.
- Tuning accuracy **within 2 cents**. Fine tune and Transpose accurate **within 1 cent**.

**Ambience**
- Default volume **25%**.
- Dips by **4 dB** while playing and recovers over **about 2 s**.
- Every level change cross-fades over **≥ 2 s**.
- Panic silences the instrument, never the ambience.

**Living Sky**
- Quick cycle: day lasts **2–60 min, default 12**. The moon advances **1/8 cycle per quick day**.
- City list of **about 200 cities**. Default city = the one matching the Mac's time zone, then UTC.
- **Random beautiful weather:** a new weather every **5–20 min**, transitions about **60 s**.
- Lightning goes through `FlashLimiter` and Gentle visuals.

**Visuals**
- Smooth rules apply to every new layer:
  - ≤ 1 MP
  - no per-pixel ray marching
  - noise ≤ 3 octaves
  - simulations at quarter resolution or analytic
- High and Ultra may add detail.

**Credits**
- **Credits:** text plus a Spotify link only. No artwork, logos, photos or lyrics.
- Card art is original, from the song's feeling and themes, with tempo, key and track number as easter eggs.

**Settings and naming**
- New settings fields decode tolerantly: missing or garbled values use defaults.
- **Names:**
  - Set 1 `moonlit-lake` / **Moonlit Lake** / mood *Serene*
  - Set 2 `spaceship-lounge` / **Spaceship Lounge** / mood *Dreamy, awe-struck*
  - Instruments **Felt Glass** and **Orbit Pad**
  - Visuals **Lake Ripples** and **Galaxy Warp**

## Review Focus

1. **Sample-rate change** (headphones at 44.1 kHz, interface at 96 kHz). The built-in instruments must reallocate and stay in tune. Pinned in Task 3 (`testTuningHoldsAt44_1And96k`).
2. **Large or odd host buffers** (4096 frames, or 1-frame calls). The built-in Audio Units must render correctly at any size up to `maximumFramesToRender`. Pinned in Task 3 (`testRendersAnyBufferSize`).
3. **Switching instruments while notes are held or the render thread is running.** No crash and no stuck notes, and the old DSP is freed only after rendering stops. Pinned in Task 3 (`testSwitchingWhileHeldIsSafe`).
4. **MIDI edge cases:**
  - Note-on with velocity 0 releases the note.
  - CC123 (all notes off) silences within 50 ms.
  - Sustain switches at value 64.
  - Unknown messages are ignored.

   Pinned in Task 2 (`testMIDIEdgeCases`).
5. **Polar and daylight-saving edge cases.**
  - No sunrise or sunset at high latitudes returns `nil` and draws a continuous night or day.
  - Melbourne's daylight-saving switch doesn't jump the sky.

   Pinned in Task 8 (`testPolarNightAndMidnightSun`, `testDaylightSavingIsInvisible`).

**Mood bindings**

**Design pinned from the spec:**
- 8 delay lines, base lengths in ms `[29.7, 37.1, 41.1, 43.7, 53.3, 61.3, 71.9, 83.9]`, scaled by `0.5 + 1.5·size`.

- Pre-delay 0–80 ms.
- Shimmer: +12 semitones via two crossfaded grains (80 ms window) in the feedback path, gain ≤ 0.35·shimmer.
- **Silence gate:** when input and output both stay below −120 dBFS for 0.25 s, clear all state so the output is exact zeros.

**Parameters:**
- Felt Glass: `fineTune` (−50…50, 0, cents), `transpose` (−12…12, 0, semitones), `space`, `felt`, `glass`, `warmth`, `ring`, `width` (0…1).
- Mood parameters: `mood.energy|warmth|brightness|space|motion` (0…1, default 0.5).

**Model pinned from the spec:**
- **Partials and frequencies:**
  - Up to 40 partials at MIDI ≤ 40, falling linearly to 20 by MIDI 64 and to 8 at MIDI ≥ 96. Never above 0.45·sr.
  - `fₙ = n·f₀·√(1+B·n²)/√(1+B)` (fundamental exact).
  - `log10 B = −3.8 + 1.2·((m − 62)/36)²` (rises toward both ends).
- **Unison pairs:** each partial n ≤ 12 is a pair detuned by ±(0.15 + 0.35·(n/12)) cents. The second component decays 3× more slowly at 0.3 amplitude (aftersound).
- **Hammer:**
  - Partial amplitude `aₙ = A(v) · sin(n·π/8) / (1 + (fₙ/f_c)^2.5)`.
  - `f_c = 700·(1 − 0.6·felt) · 2^(4.2·v')` Hz, where `v' = vel/127` shaped by mood.brightness (±0.15).
  - Contact attack: amplitude ramps over `4 − 3·v'` ms.
- **Decay:**
  - Partial T60 = `T0(m) · (0.6 + 1.4·ring) / (1 + fₙ/2500)`.
  - `T0` = 18 s at MIDI 21, falling log-linearly to 1.8 s at MIDI 108.
  - Felt shortens T60 by up to 35%.
- **Damper:** key up with pedal up sets T60 → 0.15 s with a 10 ms damper-noise burst at −30 dB relative to the note.
- **Thump:** noise burst 8–25 ms (shorter at higher v'), band-pass at 180–400 Hz, level `0.15 + 0.5·felt` relative to the note.
- **Glass:**
  - 6 partials at ratios `[1.0, 2.32, 4.25, 6.63, 9.38, 12.5]` of 2·f₀.
  - Swell time constant `0.3 + 1.2·(1 − mood.energy)` s.
  - T60 = 4–8 s (longer for low notes).
  - Level = `glass` dial. Upper-partial weights rise with v'.
- **Body:** four peaking filters: 110 Hz +3 dB Q1, 250 Hz +2 dB Q1.2, 1.2 kHz −2 dB Q0.9, 3.5 kHz +1.5 dB Q1. Plus a high shelf at 3 kHz of `−6 dB + 9 dB·warmth'` (warmth' = warmth with mood.warmth ±0.25).
- **Sympathetic bank:** 36 resonators on the fundamentals of MIDI 48–83, fed by dry output × 0.02, faded in over 50 ms when the sustain pedal is ≥ 64.
- **Width:** pan by pitch, `pan = width·(m − 64)/44`.
- **Space:** `space` dial plus mood.space ±0.3 sets reverb wet 0–45% and size 0.3–0.9. Shimmer is 0.
- **Output:** the master gain keeps a 10-note ff chord peak below 0.9, then `softLimit`.
- **Voices:** 32. A re-struck note re-excites the same voice. Stealing takes the quietest voice with a 20 ms fade. Partials below −80 dB are culled.

**How it works:**
- `InstrumentEngine` gains `func setMood(_ m: Mood)`, with a default no-op in the protocol extension.
- The parameter tree is built from `isd_synth_param_info`:
  - identifiers as in Task 2
  - `fineTune` in cents
  - `transpose` in semitones (indexed)
- `fullState` includes `["patchID": String]` plus every parameter value.
- **Render:** `internalRenderBlock` captures an `UnsafeMutableRawPointer` kernel box. It walks the `AURenderEvent` list, passing `.MIDI` events as `isd_synth_midi` with `eventSampleTime − timestamp.mSampleTime` offsets and parameter events as `set_param`. It renders in chunks of ≤ `maxFrames`.
- **Sample-rate changes:** `allocateRenderResources` (re)creates the kernel at the output bus's sample rate. `deallocateRenderResources` destroys it.

**Parameters:** `fineTune`, `transpose`, `space`, `bloom`, `drift`, `motion`, `shimmer`, `brightness` (0…1), plus the five `mood.*`.

**Model pinned from the spec:**
- **Oscillators:**
  - Layer A: 5 PolyBLEP saws with detune spread `±(3 + 22·drift)` cents.
  - Layer B: 3 PolyBLEP pulses (width 0.35–0.5, slowly modulated) an octave down.
  - A sine sub at −2 octaves at −12 dB.
  - Each oscillator gets its own random-walk pitch drift of up to `±(1 + 4·drift)` cents at < 0.3 Hz.

- **Bloom envelope:**
  - Attack `1 + 5·bloom'` s, where bloom' = bloom with mood.energy −0.3…+0.3 inverted (more energy means faster).
  - The cutoff goes from `180·2^(2·brightness')` Hz to `600·2^(4·brightness'·v')` Hz.
- **Amp envelope:** attack 0.4–2 s (scaled with bloom), release `2 + 6·(1 − mood.energy)` s.
- **Motion:** per-voice LFOs at 0.05–0.25 Hz on cutoff (±20%), pan (±0.4) and detune (±3 cents), all scaled by motion' (motion with mood.motion ±0.3). Plus a stereo chorus with 3 taps at 7–15 ms.
- **Space:** wet 30–60% from `space` + mood.space. `shimmer` dial sets reverb shimmer.
- **Voices:** 16, stealing as Felt Glass.
