> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship Sets 9 and 10 ("Still Places"), each with one of everything, and two new instrument cores: a plucked string and a breath wind. The new sky and weather reach every world with a sky; the temple bell is the first ambience in key; pitch bend and aftertouch reach the built-in instruments.

## Global constraints

- **Names:** sets `tea-house-snow` / **Tea House Snow** / mood *Delicate, hushed* (`Mood.delicate`); `zen-rock-garden` / **Zen Rock Garden** / mood *Ordered calm* (`Mood.orderedCalm`). - **Commits** end with the session's attribution lines.

## Review focus

1. **Bend and pressure left on**: switching instrument, world or preset with the wheel or pressure held must not leave a string bent or a flute flat (`allNotesOff` and a new note-on after a switch start neutral). Pinned in Tasks 1, 2 and 4.
2. **The bell never jumps mid-ring**: a key change while a strike rings waits for the next strike. Pinned in Task 8.
3. **Rime over hours**: accumulation stays in 0…1, melts in sun, and resets with the sky. Pinned in Task 6.
4. **Older saves**: sets, settings and credits saved by older builds decode (optional credit, new settings keys). Pinned in Tasks 3, 6 and 13.
5. **Place cards**: every set has a card (song or place), and cards stay distinct. Pinned in Tasks 3, 5 and 13.

## Rulings recorded while planning

- **The key comes from `PlayingAnalyzer`** (already a Krumhansl estimate over a decaying histogram after 8 notes), with a confidence margin added, rather than a second estimator. Cost if wrong: none.
- **The temple bell is in key; the existing chime is not changed this run.** Cost if wrong: one more source to retune next run.
- **The sky's day of the year** (`SkyState.dayOfYear`) drives the garden's season; the southern hemisphere's seasons are flipped by latitude. Cost if wrong: none.
- **The rime edge helper lives in `SkyShaders.common`** so every world shader can call it. Cost if wrong: a few more shader lines compiled per world.
- **`SkyU` grows by one row after the ripples** (`float4 still`: iridescence, rime, wind x, wind y). Cost if wrong: none.
- **RED by construction** as in the Sets 7 & 8 run (tests that reference new symbols cannot build before the implementation).
